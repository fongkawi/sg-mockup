# HEALL ESG demo (E / S / G)

เดโมหน้าจอ HEALL console ที่แทรกมิติสังคม (S) และธรรมาภิบาล (G) เข้ากับหน้าสิ่งแวดล้อม (E) เดิม
ไฟล์เดียว ไม่มี build step ไม่มี dependency นอกจาก Google Fonts (Noto Sans Thai)

- `index.html` เปิดได้ตรง ๆ ในเบราว์เซอร์ หรือเปิดผ่าน GitHub Pages
- ตัวเลขทั้งหมดเป็นข้อมูลตัวอย่าง
- ลิงก์ตรงไปแต่ละหน้า: `#home` `#dashboard` `#sources` `#report` `#portal`

## เปิดบน GitHub Pages
Settings → Pages → Source: Deploy from a branch → เลือก branch `main` โฟลเดอร์ `/ (root)`
