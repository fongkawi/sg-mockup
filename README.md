# HEALL ESG demo

เดโมหน้าจอ HEALL console ตาม product roadmap: ภาพรวม ESG (คะแนนโดยประมาณ ผลทางการเงิน เทียบกลุ่ม), แดชบอร์ด E / S / G, รายอาคาร (heatmap), ตัวชี้วัดเฉพาะโรงพยาบาล, บันทึกข้อมูล (OCR, คลังเอกสาร), ตรวจจับความผิดปกติ, อัปเดตกฎระเบียบ, เป้าหมาย KPI, งาน (รายการ/บอร์ด/ปฏิทิน), รายงาน (56-1, GRI, IFRS S2, อบก. · ระดับภาษา · ที่ปรึกษาตรวจ), น้องฮีลใจ, แหล่งข้อมูลและตัวเชื่อม PeoplePlus, ตั้งค่า (สิทธิ์ AI สำรองข้อมูล roadmap) และโหมดนำเสนอ 3D

- ไฟล์เดียว `index.html` ไม่มี build step ไม่มี library ภายนอก ใช้แค่ฟอนต์ Noto Sans Thai จาก Google Fonts
- ตัวเลขทั้งหมดเป็นข้อมูลตัวอย่าง คะแนน ESG เป็นประมาณการ ไม่ใช่ผลประเมินทางการ
- ป้าย "ระยะ 1/2/3" บอกว่าฟีเจอร์นั้นอยู่ระยะไหนของ roadmap ปิดได้ที่ ตั้งค่า › แผนพัฒนา
- ลิงก์ตรงไปแต่ละหน้า: `#home` `#dashboard` `#entry` `#anomaly` `#updates` `#kpi` `#tasks` `#report` `#ai` `#sources` `#settings` `#portal`
